# 批量法规 TXT 示例

运行以下命令可从项目记录的官方来源重新生成示例：

```powershell
python scripts\generate_batch_law_samples.py
```

生成结果：

- `examples/batch_laws/`：200 个可在知识库管理页多选上传的 UTF-8 TXT；
- `examples/batch_laws_manifest.json`：法律领域、来源地址与文件对应关系。

每个 TXT 的格式固定为：

```text
第一行：法律名称
第二行：条号
第三行：来源
第四行起：正文，可以包含多行
```

200 条数据来自 10 部法律，每部选取前 20 条，覆盖劳动用工、消费者权益、资源与环境、广告合规、公平竞争、价格监管、计量监管、药品监管、电子商务和食品安全。

这些文件用于知识库导入和工程演示。生成脚本会校验数量、字段长度和四行结构，但网页内容可能更新，正式使用前仍应核对法规效力状态及权威原文。
